Project Overview

RoboRun was developed in Unity using C# and focused on building gameplay systems and creating a playable game world.

My work included gameplay systems and creating a large portion of the game's map and overworld.

Overworld

Worked on the game's overworld and playable environment.

Map Development

Created a large portion of the game's map and helped establish the playable world.
