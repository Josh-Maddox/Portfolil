I Am the Wall

Game Jam Project

I Am the Wall is a Godot game jam project created for the You Are the Weapon game jam.

I AM THE WALL GAMEPLAY IMAGE

Project Overview

I Am the Wall was created as a game jam project using Godot.

The project gave me experience working within a limited development period while contributing to the game's visual direction, design, artwork, and animation.

My Contributions

Pixel Art

Created most of the pixel artwork used throughout the project.

Animation

Created most of the pixel animations used in the game.

Color Palette

Created the color palette used to establish the game's visual style.

Game Design Document

Worked on the game design document and helped define the direction of the project.
